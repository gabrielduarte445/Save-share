# Save-share
#Sobre o projeto
O Save & Share é uma plataforma digital desenvolvida com o objetivo de conectar pequenos comerciantes locais a consumidores, promovendo a redução do desperdício de alimentos e ampliando o acesso a produtos de qualidade por preços mais acessíveis.
A aplicação permite que comerciantes cadastrem produtos que, apesar de fora dos padrões estéticos, ainda estão próprios para consumo, enquanto consumidores podem visualizar, selecionar e realizar pedidos de forma simples e rápida.
Mais do que um marketplace, o projeto busca gerar impacto social, incentivando o consumo consciente, fortalecendo a economia local e contribuindo para um sistema mais sustentável.
